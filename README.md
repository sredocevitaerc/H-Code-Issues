# H-Code Issue Tracker

This public repository is the support and bug tracker for the H-Code JetBrains IDE plugin.

## Report a Bug

[Open a structured bug report](https://github.com/hackus/H-Code-Issues/issues/new?template=bug-report.yml)

Before submitting:

1. Search open and closed issues for the same problem.
2. Confirm the problem is reproducible.
3. Collect the H-Code version, IDE name and version, operating system, configured terminal shell, and affected provider.
4. Remove credentials, tokens, private paths, and other sensitive information from logs.

## Scope

Use this repository for:

- Plugin crashes or errors
- Shell detection failures
- Codex or Claude Code launch failures
- Provider detection, usage-limit handling, and automatic handoff failures
- Incorrect terminal command formatting
- Windows, macOS, Linux, WSL, PowerShell, Command Prompt, Git Bash, zsh, bash, or fish compatibility problems

Do not use this repository for issues in Codex or Claude Code themselves. Report provider product issues through their respective support channels.

## Source Code

The H-Code source repository is currently private. This public tracker intentionally contains no plugin source code, credentials, signing material, or Marketplace secrets.
